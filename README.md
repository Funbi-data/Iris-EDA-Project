# Iris Dataset Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) and data preprocessing using the Iris dataset.

The analysis was performed using Python libraries such as Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn to explore relationships between flower measurements and species classification.

---

## Objectives
- Understand the structure of the Iris dataset
- Perform data cleaning and preprocessing
- Analyze feature relationships
- Visualize patterns and distributions
- Prepare data for machine learning models

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

---

## Dataset Features
The dataset contains:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

---

## Exploratory Data Analysis Performed

### 1. Pairplot Analysis
Used Seaborn pairplots to visualize relationships between numerical features and species categories.

### 2. Correlation Heatmap
Generated a heatmap to identify strong positive and negative correlations among features.

### 3. Species Distribution
Visualized the count of flower species to confirm dataset balance.

### 4. Feature Distribution
Analyzed Sepal Length distribution using histogram and KDE plots.

### 5. Boxplot Analysis
Detected feature spread and possible outliers.

### 6. Feature Scaling
Applied StandardScaler to standardize numerical features for machine learning preparation.

---

## Key Insights
- Petal Length and Petal Width showed strong correlation with flower species.
- Setosa species was clearly separable from other species.
- The dataset was balanced across all species categories.
- Feature scaling improved consistency across numerical variables.
- Petal measurements were identified as the strongest predictive features.
